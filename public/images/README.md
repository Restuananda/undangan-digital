# Photography

Drop the couple's real photos here using these exact filenames
(referenced from `src/data/wedding.ts`) and the elegant placeholder
tiles across the app will be replaced automatically:

- hero.jpg — main cover / Home screen photo (portrait or tall, looks best around 1200×1500px)
- story-01.jpg … story-04.jpg — one photo per Story chapter
- gallery-01.jpg … gallery-08.jpg — Gallery screen photos

Recommended: export at 1600px on the long edge, JPEG quality ~80,
so the app stays fast on mobile connections.
